# Slate Drift Console

Companion implementation for the Slate Drift Console catalog item.

**Status: Released** — v0.9.1 (2026-09-03)

Slate Drift Console compares configuration trees from two environments and
shows the exact key paths that drifted.

## Migration note

This project moved out of the former `farrier-tools` organization.  The copy
under that account is obsolete; this repository is the canonical home.

## Layout

- `src/slate_drift/` — comparison engine and console entry point
- `tests/` — automated checks
